# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in **FaceVault AI**, please report it directly by contacting the project maintainer [jarifovi](https://github.com/jarifovi).

Please do not disclose security issues publicly until a fix is released.
