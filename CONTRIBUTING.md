# Contributing to FaceVault AI

Thank you for your interest in contributing to **FaceVault AI**! Developed by [jarifovi](https://github.com/jarifovi).

## How to Contribute

1. **Fork the Repository**: Click the 'Fork' button on GitHub.
2. **Clone your Fork**:
   ```bash
   git clone https://github.com/<your-username>/face-vault-Detection.git
   cd face-vault-Detection
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/my-new-feature
   ```
4. **Install Dependencies & Run Tests**:
   ```bash
   pip install -r requirements.txt
   pip install -r requirements-dev.txt
   pytest
   ```
5. **Commit Your Changes**: Keep commits clear, concise, and descriptive.
6. **Push and Open a Pull Request**: Submit your PR targeting the `main` branch.

## Code Style

- Follow **PEP 8** guidelines.
- Use explicit type annotations where appropriate.
- Include unit tests in `tests/` for new logic or bug fixes.

Thank you for helping improve FaceVault AI!
